# kaoyan-essay-coach · 考研英语作文批改教练

一个跑在豆包（Doubao）上的 Skill：按考研英语一/二官方档位给作文评分、逐句润色（母语者版 + 考研安全版）、结合地区"水旱区"民间经验做区间提示、用"学习档案卡"记住你的历史错误并长出个人模板。

> ⚠️ **免责声明（先读）**
> - 所有分数、档位是 AI 依据公开大纲做的**模拟评分**，仅供练习参考，**不构成官方阅卷结果**，正式成绩以考试为准。
> - "水区/旱区/评分偏松偏紧"全部来自考研网络社区的**民间经验汇总**，教育部教育考试院及各省考试院**从未官方划分**水旱区。
> - 地区数据**只做区间提示，不改变全国基准分**，不代表你实际会得多少分。
> - 地区数据更新于 **2026-10-02**，每年阅卷组、大小年都会变化，使用前请自行交叉核实。

---

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 双引擎评分 | 考研阅卷引擎按官方五档定档（英一/英二、大小作文分开），母语润色引擎把表达优化落地为"考研安全版" |
| 输入门槛 Gate | 考试类型 / 作文类型 / 题目 / 作文原文 四项缺任一不评分，分批追问；地区开跑前必确认 |
| 逐句前后对照卡 | 原句红标错误 → ↓ → 纠正绿标 → 卡内图例讲知识点，不用四列表格 |
| 地区校准 | 31 省水旱区知识库，只给区间提示（≤1 档），附证据链接、置信度、争议标记 |
| 学习档案卡 | 高频错误 Top5、已掌握项、分数趋势，可复制续接，不依赖平台长期记忆 |
| 个人模板卡 | 从你高分句里抽功能句（主推+2 备选），内置"烂大街句"黑名单防雷同 |
| 隐私脱敏 | 批改前自动把姓名/学校/考号换成占位符，不写进档案 |

## 🚀 安装

1. 把整个 `kaoyan-essay-coach/` 文件夹放到豆包 Skill 目录下：
   - Windows: `C:\Users\<你>\.doubao\agent_mode\workspace\.user_skills\`
   - macOS: `~/.doubao/agent_mode/workspace/.user_skills/`
2. 重启豆包，新开对话，直接发："帮我批改这篇考研英语作文"并附上作文即可。
3. 第一次使用它会主动问你：考英一还是英二、目标院校在哪个省、目标分多少——按提示答即可。

## 📊 数据来源与置信度

- **评分标准**：来自教育部考试中心发布的《全国硕士研究生招生考试英语（一/二）考试大纲》写作部分的五档描述。
- **地区倾向**：来自知乎、小红书、B 站、考研机构公开分析等多源民间经验，每条记录标注了来源数、样本量、置信度（高/中/低）、是否争议大、是否"只提示不调分"。
- **模板与表达库**：为通用写作规则整理，不复制任何受版权保护的出版物原文。

## 🔒 隐私

- 你的作文只在本次对话里批改，不会被 Skill 另存数据库。
- 姓名、学校、考号、手机号等会在批改前自动替换为占位符，不写进档案卡。
- 学习档案卡是一段可复制的纯文本，由你自己保存、下次粘贴，不依赖云端账户。

## 🔄 更新

- 地区数据：编辑 `references/region_kb.json`，同步更新 `version` 和 `updated` 字段。
- 发现某省数据不准 / 有新反馈：直接改对应省份的 `confidence`、`note`、`evidence_urls`。
- 评分规则以考试大纲最新版为准，大纲变动时更新 `references/scoring_redline.md`。
